# 라벨 (팔별: LONG, SHORT 각각, 결정 시점 t의 다음 1분봉 시가 진입 기준)
최대 관측 창 Hmax: 1h → 8시간, 4h → 48시간.
1. 지속 길이 D (상위봉 개수): 진입 후 상위봉 종가 기준, 진입가 대비 불리 방향 k·ATR_T 이상 되돌림이 처음 생긴 봉까지의 봉 수. ATR_T = 직전 14개 상위봉 ATR(인과). k ∈ {1.0, 2.0}. Hmax까지 없으면 Hmax(검열 표시).
2. 포착 수익 C (bps, 비용 전): 같은 k의 상위봉 종가 기준 트레일링 청산(최고 유리 종가 대비 k·ATR_T 되돌림한 봉 종가에서 청산, Hmax면 시간 청산)으로 실현되는 수익.
3. MFE (bps): Hmax 안 최대 유리 이동(1분봉 고가/저가).
학습 행 조건: t + Hmax(분) < 해당 fold stop_start (라벨 창이 STOP을 넘지 않음). 이 조건을 테스트로 고정.

# 모델 (fold별, 팔별)
- M_dir: R2-12 방향 binary 재사용(예측 그대로 로드).
- M_C: C 회귀(RMSE). M_D: log(1+D) 회귀. 각 k별.
- M_Cq: C의 분위 회귀 q=0.25 (Quantile:alpha=0.25) — 보수적 포착 하한.

# 거래 규칙 (모두 단일 포지션, 보유 중 신호 버림, 비용 4 bps, 펀딩 반영)
진입: E0 = 결정 시점 다음 1분봉 시가.
측면 선택 후보:
- R_DIR: R2-12 규칙(edge 큰 쪽) + 고정 보유(1h 60/120/240, 4h 240/480). 기준선.
- R_C: 팔별 예측 C 중 큰 쪽, 그 값 > θ 일 때만. θ ∈ {4, 8, 16} bps.
- R_Cq: 예측 q25 C 큰 쪽 > θ.
- R_DIR+C: 방향 edge > 0 인 쪽의 예측 C > θ.
청산 후보:
- X_FIX: 고정 보유 h (위 목록).
- X_PRED: 예측 D 상위봉 개수만큼 보유(반올림, 최소 1, 최대 Hmax).
- X_TRAIL: 라벨과 같은 k·ATR_T 상위봉 종가 트레일링(Hmax 시간 청산). 체결가 = 청산 신호 봉 종가 다음 1분봉 시가.
θ와 k는 DEV에서 고르지 말고 전 칸 보고.

# 평가 (DEV/HOLD_B, HOLD_B 탐색)
- 라벨 분포: 팔별 C·D·MFE 분포, 검열 비율.

  가장 중요: "예측 C 상위 십분위의 실현 C − 4 bps"가 양수인가.
- 그리드: T × 규칙 × θ × 청산 × k × 게이트 전 칸 — n, 롱/숏 n·net, net, 보유 시간 중앙값, 상위 1/2/5건 제거, 적중률, PW + 대체 CI, 월별·연도별.
- 기준선: 같은 진입·청산의 항상 롱, 반대 방향, 무작위 방향 1,000회 백분위, 무작위 진입 시점(같은 n) 1,000회.
- R2-12 같은 신호 시간봉·보유와 나란히 비교.
