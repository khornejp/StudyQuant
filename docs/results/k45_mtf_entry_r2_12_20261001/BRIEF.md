# 사용자 지시
"타점이 1시간·4시간봉으로 뜨면 거래는 15분·30분봉으로 정밀하게 잡아라."

# 구조
1. 상위 시간봉 신호 (T ∈ {1h, 4h})
   - 1분봉을 UTC 경계로 1h/4h OHLCV로 집계(닫힌 봉만). 결정 시점 = 상위봉 종가 시각.
   - PatchTST 게이트: 결정 시점 직전까지의 가장 최근 게이트 값(15분 격자 OOS 예측, 미래 사용 금지). 게이트 사용 여부 두 가지(사용/미사용) 모두 보고.
   - 방향 모델: CatBoost (R2-1 팔별 binary와 같은 walk-forward·피처 선택 규칙). 피처 = 기존 레지스트리 피처를 결정 시점 값으로 + 상위봉 집계 피처(최근 1/3/6/12개 상위봉 수익률, 범위, 거래량 비율).
     라벨 h = 상위봉 기준 보유: 1h 신호 → h ∈ {60, 120, 240}분, 4h 신호 → h ∈ {240, 480}분. 롱 1[r_h > +4], 숏 1[r_h < −4].
   - CatBoost 파라미터는 고정(depth 4, lr 0.05, 500회, l2 3, seed 20261001). R2-11에서 STOP 튜닝이 기각됐다.
   - 신호: 팔별 edge = p − p*(train 손익분기), 큰 쪽(>0) 하나.
2. 하위 시간봉 진입 (E ∈ {15m, 30m}) — 신호 후 대기창 W = 상위봉 1개 길이 안에서
   - E0 (기준): 신호 시점 close에 즉시 진입.
   - E1 되돌림 지정가: 신호 시점 가격에서 롱은 k·ATR_E 아래, 숏은 위에 지정가. 이후 E봉 저가/고가가 닿으면 그 가격에 체결. k ∈ {0.25, 0.5, 1.0}, ATR_E = 직전 14개 E봉 ATR(인과).
     W 안에 안 닿으면 **거래 없음**(미체결로 기록, 체결률 보고). 체결 가정으로 채우지 마라.
   - E2 하위봉 확인: W 안에서 E봉이 신호 방향으로 마감(롱: 종가>시가 & 종가>직전 E봉 고가)한 첫 봉 종가에 진입. 없으면 거래 없음.
   - 청산: 진입 후 h분 시간 청산(진입 시각 기준). stop/TP 없음.
3. 단일 포지션, 한 번에 한 방향, 보유 중 신호 버림. 비용 4 bps, 펀딩 반영.

# 평가 (DEV/HOLD_B, HOLD_B 탐색)
- 상위봉 모델 확률 품질(Spearman, 월 일치, 십분위).
- T × h × E × 진입규칙(E0/E1 k/E2) × 게이트 유무 전 칸: n, 체결률, 롱/숏 n·net, net, 상위 1/2/5건 제거, 적중률, PW + 대체 CI, 월별·연도별.
- 진입 개선 분리: 같은 신호에서 E1/E2 진입가 − E0 진입가(방향 기준 bps), 그리고 미체결 신호의 사후 r_h(놓친 기회).
- 기준선: 반대 방향, 무작위 1,000회 백분위, 항상 롱(같은 진입·보유).
- R2-8/R2-10 15분 격자 결과와 같은 보유 시간끼리 비교.
