# 강화학습 매매 정책 설계 (R2-48)

작성 2026-10-07. 사용자와 brainstorming으로 합의한 내용이다. 실행 전 동결 대상이다.

## 0. 목적과 범위

- 목적: 변동성 탐지기(R2-44 w730_raw) 출력과 기법 24종 신호를 입력으로, 15분마다 롱·숏·쉬기를 직접 결정하는 강화학습 정책을 만든다. 비용 차감 후 처음 보는 데이터에서 C1_X, 단일 기법 최고, 지도학습 정책보다 나은지 검증한다.
- 사용자 결정:
  - 결정 범위 C(직접 매매). 모델이 판단한다.
  - 판단 주기 15분.
  - 학습은 순수 강화학습(정답 라벨·모방 사전학습 없음). 기법 신호는 입력으로만 쓴다.
  - 보상의 손실 페널티 λ=2, 낙폭 페널티 μ=1.
  - 학습 종료는 "검증 구간 최대 수익" 시점(학습 구간 최대가 아님).
  - 상태 S1(8시간)과 S3(8시간+요약) 둘 다 학습해 비교.
  - 롤링 검증 A안(3개월 간격, 확장형 학습).
  - 엔진 고도화 항목 A1~A4, B1~B4, C1~C3, D1~D3 전부.
  - 평가는 1배 bps. $100·레버리지 시험은 이번 범위 밖(엔진에는 구현만).
  - 거래 수 하한 기준 없음.
  - 결과가 나빠도 어떤 기법·정책·결과도 버리지 않는다.
- 유지 원칙: 1단계(변동성 탐지)와 2단계(매매)는 분리한다. 탐지기는 재학습·수정하지 않고 동결 예측만 읽는다. 라이브 주문·인증 없음. 결과를 본 뒤 정의·기준을 바꾸지 않는다.

## 2. 백테스트 엔진 재작성 (`btcusdt_quant/backtest/`)

R2-47 코드는 폐기한다(신호를 과거 결과 파일에서 가져와 2023-12 이전 신호 0건, 그리드 대용 로직, 상수 100bps, 진단 이름표만 기록). 재사용 대상은 검증된 부분뿐이다: C1_X 재현 로직, 같은 분 재진입 금지 규칙, 분 단위 손익 원장 개념.

| 모듈 | 책임 |

| position | 단위 분수(분할·그리드), 보유 중 신호 버림, 같은 분 재진입 금지 |
| ledger | 분 단위 MTM 원장 하나. 거래별·일별·구간 손익, 비용·펀딩. 구간 밖 손익은 구간 밖 |

### 2.2 검증 장치

- A1 독립 참조 구현: 단순·느린 파이썬 참조 엔진과 결과를 소수점까지 대조.
- A2 성질 기반 테스트: 무작위 시세·신호 생성으로 불변 조건(원장 합 = 거래 합, 보유 중 진입 0, 미래 데이터 사용 0, 구간 밖 손익 0) 검사.
- A3 변이 테스트: 핵심 비교·경계 코드를 변형했을 때 테스트가 실패하는지 확인.
- A4 모의 장부 동일 코드: 모의 장부(`btcusdt_quant/paper`)가 엔진의 체결·회계 모듈을 쓰도록 연결. 연결 후 기존 모의 장부 거래를 재계산해 일치 확인.
- 사전 점검: C1_X DEV 거래 367건·net 9,230.67bps 정확 재현. 기법별로 손으로 만든 짧은 시세에서 기대 신호 대조, 실제 데이터 거래 수와 표본 거래 10건 보고.

## 3. 기법 24종 단독 롤링 백테스트

- R2-47 카탈로그(K01~K24 + 합성 장부 B1~B3) × 관문(NONE/고정) × 청산(NATIVE/DETEXIT). DETEXIT는 R2-46 정의(손절·익절 E×1.0, 절반 익절, 본전 손절, 분할 진입).
- 롤링 일정은 §5와 같다. 각 테스트 구간에서 "직전 구간 최고 기법"을 다음 구간에 적용한 결과가 비교 기준 ②가 된다.
- 결과는 통과 여부와 무관하게 전부 보관한다.

## 4. 강화학습 환경

| 요소 | 정의 |
|---|---|
| 판단 주기 | 15분. T 이전 완결 데이터만 사용 |
| 행동 | 롱 / 숏 / 쉬기. 반대 방향 선택은 청산 후 반대 진입, 쉬기는 청산. 체결 T+1분 시가(학습 시 지연 무작위화). 크기 1단위 |
| 상태(공통) | 탐지기 예측 15개(로그)·M·L·결측 표시, 기법 24종 신호(+1/−1/0)와 마지막 신호 후 경과 시간, LS·OI 변화·taker LS·funding·premium, 내 포지션(방향, 보유시간, 평가손익, 진입 후 최대 불리 폭), 시간(요일·시각 사인/코사인, 펀딩 정산까지 남은 시간) |
| 상태 S1 | 공통 + 15분봉 수익률·변동폭·거래량·taker 비중 최근 32개(8시간) + 1h·4h 요약 |
| 상태 S3 | S1 + 24시간·7일 요약 약 10개(수익률, 실현 변동성, 고저 대비 위치, 거래량 비율, funding·OI 추세) |
| 정규화 | 각 롤링 단계의 학습 구간 통계로만 표준화 |
| 보상 | 15분 순손익(bps, 비용·펀딩 차감) − 2×max(0, −순손익) − 1×(최대 낙폭 증가분) |
| 에피소드 | 학습 구간 안 무작위 시작, 2주(1,344스텝), 종료 시 강제 청산 |
| 무작위화(학습만) | 비용 4~12bps, 지연 1~5분 및 실측 분포, 슬리피지 0~10bps |
| 결측 | 탐지기·핵심 입력 결측 시 신규 진입 금지(쉬기만), 청산 허용 |
| 일치 검증 | 같은 행동 열에 대해 환경 손익 = 엔진 백테스트 손익(소수점까지) |

## 5. 학습

| 항목 | 정의 |
|---|---|
| 알고리즘 | PPO, 이산 행동 3개, 모방 사전학습 없음 |
| 네트워크 | 시계열 인코더(1D 합성곱 또는 GRU, 은닉 64) → 정책·가치 MLP 64 |
| 규제 | 드롭아웃 0.1, 가중치 감쇠 1e-4, 엔트로피 0.01, 기울기 자르기 0.5 |
| 롤링 | 2022-03 시작. 확장형 학습 구간 → 다음 3개월 검증 → 그다음 3개월 테스트. 3개월씩 전진해 2025-12까지. 테스트 이어붙임 2023-09~2025-12(약 11구간). 검증 직전 1일 비움 |
| 학습 종료 | 일정 스텝마다 검증 구간 순손익 측정, 최고점 저장, 연속 N회 무개선이면 종료, 최대 스텝 상한 |
| 테스트 | 저장 모델로 다음 3개월 1회 평가. 결과로 설정 변경 금지 |
| 시드 | 5개. 판단은 중앙값, 정책은 5개 앙상블 다수결 |
| 하이퍼파라미터 | 학습률 {1e-4, 3e-4} × 인코더 {합성곱, GRU}. 각 롤링 단계의 검증 구간에서만 선택 |
| 규모 | 상태 2 × 하이퍼파라미터 4 × 시드 5 = 40, 롤링 약 11단계 ≈ 440회 학습. 1단계 실측 후 예산표 작성, 과대하면 시드 3개로 줄이는 것을 사용자에게 확인 |
| 가짜 데이터 대조 | 시간 순서를 블록 단위로 섞은 데이터에서 같은 설정으로 학습. 그 수익 분포를 과적합 기준선으로 사용 |
| 지도학습 기준선 | 시점마다 롱·숏·쉬기의 다음 N시간 비용 차감 수익을 예측해 최고 행동 선택(전환 억제 장치 포함). 비교용으로만 사용 |
| 시험 수 | 정책 단위 8(상태 2 × 하이퍼파라미터 4)을 대장에 추가 |

## 6. 평가와 판정

- 주 평가: 롤링 테스트 구간 이어붙임(2023-09~2025-12). 학습·선택에 쓰지 않은 구간.
- 비교 기준: ① C1_X ② 단일 기법 최고(직전 구간 기준 선택) ③ 지도학습 정책 ④ 무작위 정책(같은 거래 빈도) ⑤ 항상 쉬기 ⑥ 바이앤홀드. 비교는 일별 순손익 차이.
- 통과 기준(S1, S3 각각, 결과 전 고정):
  1. 4bps 순손익 > 0.
  2. ①, ②, ③ 대비 일별 차이의 stationary bootstrap 95% 하한 > 0.
  3. HAC 알파 95% 하한 > 0.
  4. 누적 시험 수 반영 DSR ≥ 0.95.
  5. 상위 2거래 제거 순손익 > 0, 8bps 순손익 > 0.
  6. 시드 5개 중 4개 이상 순손익 > 0.
  7. 가짜 데이터 대조 수익의 95% 분위 초과.
- 최종 확인: 통과 정책만 2026-01~06 1회. 순손익 > 0, C1_X 대비 ≥ 0. 이후 새 T0 모의 장부로 실시간 검증.
- 진단(전부 보고): 반기·국면·롱숏·시간대별, 비용 0/4/8/12bps, 지연 1/2/5분·실측, 봉 내부 경로 민감도, 몬테카를로, PBO, White, Hansen SPA, 행동 분포(롱/숏/쉬기 비율, 보유시간, 월 거래 수), 입력 중요도, 시드 간 일치도, 국면·기법 신호별 행동 집계.
- 실패 시: 정책과 결과 전부 보관, 부족 요인 진단, 후속 설계는 별도 실험으로 사전 등록.

## 7. 위험

- 강화학습은 시뮬레이터 허점을 악용한다. 엔진 검증(§2.2) 통과 전에는 학습하지 않는다.
- 2024~2025는 탐지기 예측 검증과 버그 있던 R2-45에서 이미 열람됐다. 최종 판정은 2026H1 1회와 모의 장부로 한다.
- 손실 페널티가 커서 정책이 거래를 멈출 수 있다. 그 결과도 그대로 보고한다. 거래 유도 보상은 넣지 않는다.
- BTC 장세 변화로 과거 학습이 무효해질 수 있다. 롤링 단계별 성과 편차를 보고한다.
- 학습 규모가 커서 GPU 시간이 길다. 실측 후 예산을 사용자와 확인한다.
